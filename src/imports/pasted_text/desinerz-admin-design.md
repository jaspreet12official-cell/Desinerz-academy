Design a modern, minimal admin dashboard / CRM panel for "Desinerz Academy," a design and tech training institute. The visual language should feel like Microsoft Azure Portal or AWS Console — enterprise-grade, calm, data-dense but never cluttered, built for daily operational use by non-technical staff.

Design system rules (apply to every screen):
Use a light theme by default: off-white/very light gray canvas background (
#F7F8FA or similar), pure white content cards with a 1px hairline border (
#E5E7EB) instead of heavy drop shadows, 8–12px corner radius on cards and buttons. Base text is near-black slate (
#1A1D21) on light backgrounds — never pure black on saturated color. One primary brand accent color (deep indigo/purple, matching the Desinerz "D" logomark) used sparingly for primary actions, active nav states, and links only — not decoratively. Neutral grays for secondary UI. Semantic colors used only for status: green for success/paid, amber for pending/dues, red for delete/error/invalid — and every colored button or badge must pair a dark saturated fill with white text (never dark text on a saturated fill, never a light pastel fill with black text sitting directly adjacent to a saturated one). Maintain WCAG AA contrast (4.5:1 minimum) on every text/background pair, including inside colored badges and table status pills. Typography: one clean sans-serif (Inter or SF Pro style), clear hierarchy — 24px page titles, 14px body, 12px muted metadata/labels, medium weight for numbers in stat cards. Iconography: thin-line, single-weight icon set (like Fluent UI or Lucide icons), monochrome by default with accent color only for the active/selected state.

Global layout:
Persistent left sidebar (240px, white background, hairline right border) with the Desinerz Academy logomark at top, grouped nav sections with small uppercase section labels ("Overview," "Content," "Academics," "Operations"), each item with icon + label, active item shown with a soft indigo-tint background and a left accent bar (not a filled color block). Collapsible sub-menu for "Page Management." Top bar is white, thin border-bottom, breadcrumb-style page title on the left, and on the right a search field, notification bell, and account menu with avatar — no bare "Log Out" text link floating alone.

Pages to generate (as one connected flow, shared components/styles across all):

Dashboard — Replace the current flat colored-icon tile grid with an Azure-style KPI overview: a top row of 4 compact metric cards (Total Students, Total Courses, Total Enrollment Requests, Total Get In Touch) each showing a large number, a small trend/delta indicator, and a subtle sparkline or icon in a muted tint box (not solid saturated circles). Below, a two-column layout: a "Courses by Category" breakdown (Design, Digital Marketing, Govt Typing, Development, Computer Basics, Data Analytics, Power BI) as a horizontal bar list or donut chart, and a "Recent Activity" panel (recent enrollments, recent inquiries) as a clean list with avatars/initials and timestamps.
Page Management → Home Page — Two card sections (Header Image, Footer Image) each with a bordered image preview frame, a modern drag-and-drop upload zone (dashed border, upload icon, "Drag & drop or browse" copy) replacing the raw <input type=file> look, and a filled indigo primary button.
Page Management → About Us — A rich text editor card with a cleaned-up toolbar (icon-only buttons in a light gray toolbar strip), a live preview pane beside or below it, and a separate "Top Image / Video" card with a segmented control (Image / Video Link toggle) styled as a pill switch instead of radio buttons.
Page Management → Universities — Empty-state and populated table view: a data table with rounded card container, column headers in muted uppercase small text, image thumbnails as rounded squares, star rating shown as filled/outline star icons (not a number), and row actions as icon buttons (edit/delete) revealed on hover, plus a clear empty-state illustration + "Add University" CTA when no rows exist.
Page Management → Contact Us — Three-column repeating card group (Heading / Content / Image) redesigned as a single clean form card with labeled input fields (floating or top-aligned labels), and a compact image upload chip with thumbnail preview.
Page Management → Gallery — A modern masonry/grid photo manager: upload dropzone at top, uploaded images shown in a responsive grid with rounded corners, a subtle hover overlay containing a small trash icon button (not a full-width red "Delete" bar under every image).
Page Management → Terms & Conditions / Privacy Policy — Long-form rich text editor pages, styled identically to About Us's editor card, with Meta Title / Meta Description as a separate "SEO" collapsible card below the main content.
Page Management → Events — Table with Name / Image / Actions columns in the same data-table style as Universities, plus a clear empty state ("No events yet — create your first event") instead of a bare "No events available" text row.
Courses — Card-based or table-based course catalog: course thumbnail, name, fee (formatted currency), rating as stars, and Edit/Delete as small icon buttons with a subtle hover background instead of solid pill buttons competing with each other in every row.
Students → Enrollment — Dense data table (Reg No, Student with avatar, Course, DOB, Actions) with alternating subtle row hover, sticky header, search + filter bar above the table, and Edit/Fees/Delete consolidated into a single "..." overflow menu per row to reduce visual noise, or three small tonal icon buttons instead of three solid colored pill buttons.
Students → Certificate — Certificate/marksheet validity table with status shown as a pill badge: green "Valid" (white text on solid green) / red "Invalid" (white text on solid red) instead of plain colored text, plus a cleaner "Toggle Student Selection" control styled as a segmented button.
Subjects — Same clean data-table pattern (Subject Name, Code, Course, Actions), consistent empty state, primary "Add Subject" button in indigo (not green) to stay consistent with the single-accent-color rule.
Fee Structure — A finance-grade dense table (Name, Course, Phone, Receipt No., Total Fees, Discount, Final Amount, Paid, Dues, Last Paid Date) with right-aligned numeric columns, currency formatting, Dues shown in red only when non-zero, Paid shown in green only when non-zero, sortable column headers, a search input, and the Copy/CSV/Excel/PDF/Print export actions redesigned as a single icon-button group in the top-right (Azure-style "Export" split button) instead of five separate gray buttons in a row.
